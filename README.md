# ইসলামিক মাহফিল ফটোফ্রেম ওয়েবসাইট

## GitHub Pages-এ প্রকাশ করার নিয়ম
1. GitHub-এ লগইন করে **New repository** তৈরি করুন।
2. Repository-র নাম দিন, যেমন `mahfil-photo-frame`।
3. এই ZIP-এর ভেতরের `index.html` এবং `frame.jpg` ফাইল দুটি repository-তে আপলোড করুন।
4. Repository-র **Settings → Pages** এ যান।
5. **Deploy from a branch** নির্বাচন করুন।
6. Branch হিসেবে `main` এবং folder হিসেবে `/ (root)` নির্বাচন করে Save করুন।
7. কিছুক্ষণ পর GitHub Pages-এর দেওয়া লিংকে ওয়েবসাইট চালু হবে।
